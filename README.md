# Mastermind — Python Colour-Guessing Game

A Python implementation of the classic Mastermind game, developed as a group project for the BSc Computer Science programme at Technological University Dublin.

The project focuses on game logic, algorithmic problem-solving, input validation and automated software testing.

## Features

- **Two Game Modes:** Player vs Computer and Computer vs Player.
- **Random Code Generation:** Generates a secret combination of four colours.
- **Guess Validation:** Validates player inputs and provides feedback based on correct colours and positions.
- **Computer Solver:** Uses candidate elimination to narrow down possible combinations based on feedback.
- **Replay Functionality:** Allows players to start a new game.
- **Automated Testing:** Unit tests developed using PyTest to validate core functionality.

## Installation & Usage

**Requirements:** Python 3 and PyTest (for automated testing).

Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/python-mastermind-game.git
cd python-mastermind-game
```

Run the application:

```bash
python -m src.main
```

Install PyTest and run the tests:

```bash
python -m pip install pytest
python -m pytest
```
